A / RANDOMNESS

为什么不用 Math.random()？

Math.random() 面向一般计算，并不承诺不可预测性。本工具使用 Web Crypto 的加密安全伪随机数生成器，并通过拒绝采样避免取模偏差。

B / UNIQUENESS

一个密码，只给一个账户

再强的密码，一旦在数据泄露中暴露，也不该波及其他账户。使用密码管理器保存独立密码，并为重要账户开启多因素认证。

C / MULTI-FACTOR

给密码再加一道防线

多因素认证（MFA）把密码与动态验证码、安全密钥等额外因素结合。即使密码意外泄露，第二重验证仍能显著降低账户被接管的风险。

03 / GOOD PRACTICE

生成之后，怎么做？

01密码越长越好吗？+

在字符池相同且随机性可靠的前提下，增加长度会快速扩大搜索空间。日常重要账户可优先选择 16–20 位或更长，同时遵守目标网站的长度与字符规则。

02应该排除所有符号吗？+

不需要。符号能扩大字符池，但部分系统会限制可接受的符号。遇到兼容性问题时，可以减少符号并适当增加长度；不要为了达到固定长度而重复使用同一个密码。

03这个页面会记住我的密码吗？+

不会。页面没有账号系统、数据库或网络提交，也不使用本地存储保存结果。需要长期保存时，请把密码放入可信的密码管理器，而不是依赖浏览器历史或截图。
